# 開発タスク一覧(M0〜M2.5骨格)

**この文書は実装エージェント(Opus)への作業指示書である。** アーキテクトが書いた骨格(コミット済み)の上で、各タスクのTODOを実装する。

## 0. 全エージェント共通ルール

1. **担当ファイル以外を編集しない。** 共有ファイル(Models.swift / CoordinateMapper.swift / FrameComposer.swift / MappingViewModel.swift / AppServices.swift / AppDelegate.swift / Info.plist / project.yml)は読み取り専用。変更が必要だと思ったら**実装せずに質問として報告**する。
2. **推測で進まない。** 次のいずれかに該当したら、その部分の実装を止めて質問リストとして報告する(他の確実な部分は実装を続けてよい):
   - Apple APIのシグネチャ・挙動に確信が持てない(存在しないAPIを発明しない)
   - 骨格のTODOコメント・要件文書と矛盾を見つけた
   - 共有ファイルの変更が必要になった
   - 設計判断が2通り以上あり、どちらかで後戻りコストが大きい
3. **座標系規約**(Models.swift冒頭)を厳守。Y反転や座標変換をCoordinateMapper以外に書かない。
4. コードコメントは日本語。既存ファイルのスタイル(4スペース、`// MARK:`)に合わせる。
5. このリポジトリではビルド検証ができない(Linux環境)。そのぶん、**APIの使い方は確実なものだけを書く**こと。確信が持てないAPI使用は質問に回す。
6. 完了報告には「実装したファイル・満たした受け入れ条件・残TODO・質問リスト」を含める。

## 1. タスク定義

### ENG-1: テストパターン生成(`Engine/TestPatternGenerator.swift`)
- 面ごとの識別色(左壁=シアン/正面壁=マゼンタ/床=イエロー)の枠+10×10グリッド+対角線+面ラベルを、各crop領域に描いた1920×1080のCIImageを生成
- crop構成が変わらない限りキャッシュを返す
- **受け入れ条件**: `FrameSource`準拠。`update(params:)`後の`copyFrame`が非nil。crop変更でキャッシュ無効化。

### ENG-2: 動画ソース(`Engine/VideoSource.swift`)
- AVQueuePlayer+AVPlayerLooper+AVPlayerItemVideoOutput(420f YUV)のプル型実装
- **受け入れ条件**: copyFrameがhostTime基準で新フレームのみ返す。play/pause/seek/volume動作。ループ構成がAVPlayerLooper。

### ENG-3: リアルタイムレンダラ(`Engine/OutputRenderer.swift`)
- 外部UIScreenのCADisplayLink駆動。CIContext(1個・cacheIntermediates無効)でCAMetalLayerへ描画
- サーマル降格(thermalState≧serious→75%→50%)
- **受け入れ条件**: start/stop冪等。フレームなしtickで前フレーム再ワープ。drawable失敗スキップ。

### ENG-4: プリセット永続化(`Engine/PresetStore.swift`)
- Documents/Presets/へのJSON保存。要件定義書§8のスキーマ形状(surfacesがオブジェクト)に一致させる
- **受け入れ条件**: JSONの`surfaces`がオブジェクト形状(Swift 5.6+/SE-0320でString enumキー辞書はオブジェクトになるはず — テストで固定)。破損JSONでnil。lastUsed自動保存が動く。

### ENG-5: ベイク(`Engine/BakeExporter.swift`)
- AVMutableVideoComposition(applyingCIFiltersWithHandler)+AVAssetExportSessionでの書き出し、BakeStore(index.json)、進捗・キャンセル・空き容量チェック
- **受け入れ条件**: FrameComposerを流用(独自ワープ実装を書かない)。asyncで完走/キャンセル/失敗の3経路が返る。

### EXT-1: シーン管理(`Scenes/`3ファイル)
- MainSceneDelegate(UIHostingController)、ExternalSceneDelegate+OutputHostViewController(CAMetalLayer⇔AVPlayerLayer切替)、ExternalDisplayManager(結線・displayState更新・contentSource監視)
- **受け入れ条件**: 接続→投影開始、切断→停止、displayState反映。外部シーンにUI要素ゼロ。ベイク再生モードでAVPlayerLayerに切替わる。

### UI-1: キャンバス(`UI/EditorView.swift`, `UI/MeshCanvasView.swift`)
- 画面レイアウト+3面ワイヤーフレーム+12点ドラッグ(beginGesture/move)、16:9レターボックス、選択、ロック
- **受け入れ条件**: ドラッグでviewModel.moveが正規化座標で呼ばれる。タッチ判定44pt。ロック時に操作不能。

### UI-2: 周辺UI(`UI/InspectorView.swift`, `UI/TransportView.swift`, `UI/ContentPickerView.swift`, `UI/PresetListView.swift`)
- インスペクタ(数値入力・ナッジ・明るさ/ガンマ・リンクToggle・リセット/アンドゥ)、トランスポート+ベイク操作、コンテンツ選択、プリセット管理
- **受け入れ条件**: 各ファイルのTODOコメント記載の機能が一通り操作可能な形になっている。

### TEST-1: ユニットテスト(`CornerCastTests/DomainTests.swift`)
- ファイル内TODOコメントのカバレッジ一覧を実装(必要なら同ディレクトリにファイル分割可)
- **受け入れ条件**: 実装済みコードの仕様(クランプ・リンク・undo・座標変換・fingerprint)を検証するテストが揃っている。

## 4. 依存関係

- A・B・C・D・Eは**互いの完成を待たない**(骨格のプロトコル/シグネチャに対して実装する)
