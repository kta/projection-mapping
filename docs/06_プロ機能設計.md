# プロ機能設計(v1.4)— メッシュワープ / マスク / エフェクト / OSC・MIDI / テンプレート

要件v1.4: 「家庭用カジュアル」から「プロ用途にも耐える」への引き上げ。競合(MadMapper/HeavyM級)とのプロ機能ギャップを埋める。**コア(Models/FrameComposer/ViewModel)は実装済み**。本書はUI/制御系を実装するエージェントとの共有契約。

## 1. メッシュワープ(F-MESH-1)— 実装済みコア

- `WarpMesh { rows, cols, points(row-major・正規化キャンバス座標) }`。`SurfaceConfig.mesh: WarpMesh?`(nil=従来の4点補正)。
- 有効化: `viewModel.setMeshEnabled(_:for:)` / `setExtraMeshEnabled(_:id:)` — 現quadから双一次補間で4×4初期化。
- 点移動: `moveMeshPoint(surface:index:to:)` / `moveExtraMeshPoint(id:index:to:)`(クランプ込み。アンドゥはUIがドラッグ開始時に`beginGesture()`)。
- レンダリング: FrameComposerがソース片を(rows-1)×(cols-1)セルに分割し、セル単位のホモグラフィで変形(区分的射影変換・境界連続)。フェザーは分割前に適用済み。ベイク・プレビューにも自動反映。
- **UI(TASK PRO-A)**: 選択中の面がmesh非nilのとき、キャンバスは4隅ハンドルの代わりにrows×colsのメッシュ点(小さめ12pt・タッチ44pt)を表示しドラッグ可能に。InspectorViewに「メッシュワープ」Toggle(コーナー面/自由面の両方)。メッシュ有効面のワイヤーフレームはメッシュ外周を描く(quadではなく)。

## 2. 出力マスク(F-MASK-1)— 実装済みコア

- `MaskShape { id, name, quad }`、`preset.maskShapes`。最終合成の上に黒quadを重ねる(FrameComposer実装済み)。
- API: `addMask()` / `removeMask(id:)` / `moveMaskCorner(id:corner:to:)` / `translateMask(id:by:from:)`、選択は`selectedMaskID`(面選択と排他)。
- **UI(TASK PRO-A)**: キャンバスにマスクを赤(.red)のワイヤーフレーム+斜線塗り(0.15不透明)で描画。4隅ハンドル+全体ドラッグ+タップ選択。InspectorViewに「マスク」セクション(追加ボタン/選択中マスクの名前変更・削除)。

## 3. 出力エフェクト(F-FX-1)— 実装済みコア

- `EffectSettings { saturation, contrast, brightness, hueDegrees }`、`preset.effectSettings`。分割前のソース全体へ適用(全面で色調が揃う)。fingerprintに含まれるためベイク陳腐化も検知される。
- **UI(TASK UX-1)**: EffectsView(スタブ済み)にスライダー4本+リセット。

## 4. ユースケース選択(F-TPL-1)— 実装済みコア

- `MappingPreset.ProjectTemplate { cornerCockpit / freeform / sample }`(displayName/caption/systemImage付き)。`viewModel.apply(template:)`。初回起動は`viewModel.needsWelcome == true`。
- **UI(TASK UX-1)**: WelcomeView(スタブ済み)= 3枚カード。EditorViewに「新規」ボタン+初回起動時の自動表示(fullScreenCover)。

## 5. 外部制御(F-CTRL-1/2)— スタブのみ。TASK CTRL-1で実装

### 5.1 OSCアドレス空間(テストとの共有契約 — 変更禁止)

UDP待ち受け(既定ポート8000)。単一メッセージのみ(バンドル未対応可)。型タグf/i対応。

| アドレス | 引数 | 動作 |
|---|---|---|
| `/cc/corner/<leftWall\|frontWall\|floor>/<tl\|tr\|br\|bl>` | ff (x, y 0-1) | 該当頂点を移動(move) |
| `/cc/brightness/<surface>` | f (0.25-2) | 面の明るさ |
| `/cc/gamma/<surface>` | f (0.25-4) | 面のガンマ |
| `/cc/feather/<surface>` | f (0-0.3) | 面のフェザー |
| `/cc/play` | なし | 再生(activeVideoSource) |
| `/cc/pause` | なし | 一時停止 |
| `/cc/mode` | i (0=realtime, 1=baked) | 出力モード切替 |

- `OSCMessage.parse(_ data: Data) -> OSCMessage?` は**純関数**(テストTASK PRO-Tが直接検証する)。
- ViewModel適用は必ず `Task { @MainActor in }` 経由。範囲外値はクランプ。

### 5.2 MIDI固定マッピング

| 入力 | 動作 |
|---|---|
| CC 20 / 21 | 選択中頂点のX / Y(0-127→0-1) |
| CC 22 / 23 | 選択中面の明るさ / ガンマ |
| Note On 60 | 再生 / Note On 61: 一時停止 |

CoreMIDIのAPIシグネチャに確信が持てない場合は`MIDIController`をTODOのまま残し質問すること(OSCが主目標)。
