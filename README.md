# projection-mapping — CornerCast(仮称)

プロジェクター1台で部屋のコーナー(左壁・正面壁・床)に映像を投影し、家庭内に「SFコックピット風」の没入空間を作るための **プロジェクションマッピングアプリ**(iPadOS 17+ / macOS 14+(Mac Catalyst)対応)の開発リポジトリ。

iPadにUSB-C – HDMIでプロジェクターを接続し、1本の超広角動画を「3分割 → 4点射影変換 → 再合成」して出力する。iPad側は操作UI、プロジェクター側は映像のみの全画面出力(セカンドディスプレイ)。出力は**リアルタイムモード**(調整しながら即投影)と**事前レンダリングモード**(合成済み動画を書き出して再生するだけ。低負荷・低発熱で長時間運用向け)の2本立て。

## 検証のしかた

```bash
./tools/verify.sh          # 生成 → バンドル同梱の確認 → ビルド → テスト → サンプル検査(macOS + Xcode)
./tools/verify.sh bundle   # .app の直下にサンプルmp4が入るかだけ確認
./tools/verify.sh assets   # サンプル動画の実体検査のみ(macOS以外でも動く)
```

`tools/verify_samples.py` は同梱サンプルを実際にデコードして、解像度・尺・全フレームのデコード可否、
ループ継ぎ目の有無(末尾→先頭の差を通常の隣接フレーム差と比較)、
デフォルトクロップ3面それぞれに投影して見える絵があるかを実測する。CIでも走る。
`CornerCastTests/SampleVideoTests.swift` は同じ前提をアプリのバンドル側から固定する
(リソースのコピー漏れは、アプリ上ではエラーにならずサンプル欄が消えるだけなので、テストで検知する)。

開発メモ: 設計判断の記録は `docs/05_開発タスク一覧.md` §3の統合判断ログを参照。ローカルでビルドする場合は `brew install xcodegen && xcodegen generate` で `CornerCast.xcodeproj` を生成する。
