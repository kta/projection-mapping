# projection-mapping — CornerCast(仮称)

プロジェクター1台で部屋のコーナー(左壁・正面壁・床)に映像を投影し、家庭内に「SFコックピット風」の没入空間を作るための **iPad専用プロジェクションマッピングアプリ** の開発リポジトリ。

iPadにUSB-C – HDMIでプロジェクターを接続し、1本の超広角動画を「3分割 → 4点射影変換 → 再合成」してリアルタイム出力する。iPad側は操作UI、プロジェクター側は映像のみの全画面出力(セカンドディスプレイ)。
